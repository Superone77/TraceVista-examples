# Example library conventions

- Use plain language. This repository holds approved TraceVista example data, thumbnails, source notices, and license texts. The viewer, shared JSON format, conversion skill, and validation scripts live in the separate TraceVista repository.
- Keep Pi Agent first in `examples/index.json`. Each case is one complete, self-contained `.agent-state.json`; do not add separate original experiment files.
- Preserve raw event text, IDs, call/result pairing, source attachments, and source attribution. Labels and inferred relationships need cited evidence. Chronology and code ancestry are separate. Review PASS is not correctness or performance evidence.
- Keep credentials and ordinary private imports out of Git and release assets. Add, replace, or extend a public export only with maintainer approval. Record each case's source and license in `THIRD_PARTY_NOTICES.md`, and preserve license copies in `LICENSES/`.
- The Garden Animation case is a fixed excerpt: `continued:E853` through `continued:E1098`. Include only that self-contained excerpt and its thumbnail. The full session export and later videos stay out of this repository and the viewer repository.
- Run `pnpm test:examples` from the viewer checkout, setting `TRACEVISTA_EXAMPLES_DIR` if this repository is not its sibling `../TraceVista-examples`. Inspect the affected example in the viewer. Tests of exports or UI behavior are not new model runs or benchmarks.
- Commit an approved data update here before running `pnpm examples:lock -- ../TraceVista-examples` from the viewer checkout. Then run `pnpm test:examples` and `pnpm build:site`, inspect the showcase, and commit the viewer's updated `examples.lock.json`. The lock records this repository's commit and SHA-256 of served assets.
- This is an independent local data repository. Creating it does not publish it or create a remote. Publish or push only when the user authorizes remote delivery. Use development branches; integration into `main` requires a pull request and the user's explicit approval before merging.
